================================================================================
                          HOW TO BUILD APK (3 STEPS)
================================================================================

STEP 1: Install build tools (one time)
   npm install -g eas-cli

STEP 2: Authenticate and build
   cd GetFitApp
   eas login
   eas build --platform android
   
   Select "APK" when prompted (not AAB)
   
   Wait 5-15 minutes for build to complete

STEP 3: Download & Install
   Click download link provided
   Transfer to Android phone
   Open file manager and tap APK to install

TOTAL TIME: 20-30 minutes
